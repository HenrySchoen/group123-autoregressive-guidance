# Guidance of autoregressive protein language models

The course README describes the data, the evaluation pipeline and the cluster. This file describes what we built on top of it and in which order it runs.

## What we added

| File | What it does |
|---|---|
| `src/protgen/models/mlp.py` | MLP over a fixed context of three tokens, the Bengio baseline. |
| `src/protgen/models/transformer.py` | Causal decoder-only transformer, four layers, `d_model` 128. |
| `src/protgen/models/transformer_cfg.py` | The same transformer with a family label embedding added to the input, for classifier-free guidance. |
| `src/protgen/models/classifier.py` | Linear head on the frozen transformer. It scores every prefix position, so it also predicts from partial sequences. |
| `src/protgen/metrics/composition.py` | Amino acid composition and L1 distance to a family mean. This measures family membership without asking the classifier that did the steering. |
| `train.py` | Trains the MLP or the transformer. |
| `train_classifier.py` | Trains the classifier head with the backbone frozen. |
| `train_cfg.py` | Trains the conditioned transformer with label dropout. |
| `sample.py` | Unguided samples from a trained model. |
| `guidance_classifier.py` | Classifier guidance. Evaluates the predictor for all 21 candidate tokens per step and adds `lmbda` times its log probability. |
| `guidance_cfg.py` | Classifier-free guidance over a list of `w` values, including a null label run. |
| `eval_classifier.py` | Accuracy of the predictor by prefix length and on complete sequences. |
| `eval_guidance.py` | Composition of the guided samples over `lmbda`. |
| `eval_cfg.py` | The same over `w`. |
| `eval_membership.py` | Predicted family membership for every sample set, scored at the position that has seen the whole sequence. |
| `figures.py` | The five report figures, written to `report/figures/`. |

## The order things run in

```bash
uv run python train.py --model transformer
uv run python train_classifier.py
uv run python train_cfg.py
```

```bash
uv run python guidance_classifier.py --family AcyP --lmbda 1
uv run python guidance_cfg.py
```

Both write to `results/sequences/`. Scoring the samples needs a GPU, because it folds every sequence with ESMFold:

```bash
bash hpc/run_eval.sh results/sequences/guided_AcyP_lmbda1.csv
```

```bash
uv run python eval_classifier.py
uv run python eval_membership.py
uv run python figures.py
```

## What is in version control

The sample CSVs in `results/sequences/`, the training histories in `results/checkpoints/` and the figures in `report/figures/`. Checkpoints, predicted structures and the metric tables stay out, they are regenerated by the commands above.
